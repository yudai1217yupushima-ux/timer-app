
# Pomodoro Timer

作業時間と休憩時間を自動で切り替えるポモドーロ・タイマー

## Demo

[アプリを試す](https://yudai1217yupushima-ux.github.io/timer-app/)

## 概要

集中して作業する時間と休憩時間を交互に設け、中断を減らし、生産性を高めることを目的に制作しました。

## 主な機能

- 作業時間の選択（25分・50分）
- セット数の選択
- 作業終了後の休憩への自動切り替え
- 休憩終了後の次セットへの自動進行
- タイマーの一時停止・再開
- 全セット終了時の通知
